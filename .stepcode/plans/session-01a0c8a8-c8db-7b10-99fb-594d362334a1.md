# 重新设计「我的」页个人资料 —— Mini Archive（集めたもの）

## 目标与范围

**只改 `design/profile.html`（视觉基准稿），不改 `src/` 任何代码。** 把 profile 现有的深色半透明文件夹，重设计成参考图里的**暖黄色收藏夹（Mini Archive）**，含**闭合 / 打开**两种状态：

- **闭合**：暖黄色渐变圆角文件夹，带顶部标签、大标题 + 「Mini Archive」小字、底部内容占位线、右侧露出的第二层（叠放厚度）、柔和投影；鼠标指针提示可点。
- **打开**：封面沿左边缘向外翻开（CSS 3D `rotateY` 开门动效），露出扇形叠放的「邮票」收藏卡。

参考图是通用「集めたもの／邮票」；因这是用药 App 的设计稿，邮票卡**主题化为药品收藏卡**（药名 + 剂量/频次 + 「余量」角标，仿邮票面值），既贴参考图美感又是本 App 的真实设计。页面其余区块（本周概览 / 家庭成员 / 菜单 / 退出）保持不变，仅重画 `.folder-*` 这一段（CSS + HTML + 切换 JS）。

## 设计规格（贴近参考图）

调色用 `:root` CSS 变量集中管理（设计稿自成体系，不涉及 RN 的 theme token）：

| 用途 | 值 |
| --- | --- |
| 封面渐变 | `linear-gradient(160deg,#F6D472,#EDBB43)` |
| 顶部标签 tab | `#F2CA5B`（圆角在上的小凸舌） |
| 墨色标题 ink | `#4A3417` |
| 次级小字 inkMuted | `#8A7440` |
| 占位线 line | `rgba(74,52,23,0.14)` |
| 内页纸 paper | `#F7E7BD` |
| 投影 | `0 24px 48px -12px rgba(120,84,20,0.28)` |

- 大标题取中文（`我的收藏`，或沿用示例人名 `小明`）+ 小字 `Mini Archive`，对齐参考图的「CJK 大字 + 英文小字」结构。
- 圆角沿用现有 `--radius-card: 18px` 体系，文件夹取 ~28px 大圆角。
- **邮票卡**：圆角 + 齿孔边（`mask` 重复 radial-gradient 打出半圆缺口，降级用 dashed 内框）；前排一张全彩插画风药品邮票，后排叠放线稿风简卡，整体扇形微旋。

## 改动文件（唯一）

- **`design/profile.html`**
  1. `:root` 增补上述暖黄色系变量（亮色）；`@media (prefers-color-scheme: dark)` 给一套深色暖金变体，保持文件夹在深色背景下仍是「实物」观感。
  2. 重画 `.folder-cover`（暖黄渐变 + tab + 标题 + 占位线 + 右侧第二层 + 投影）；新增 `.stamp` / `.stamp--hero` / `.stamp--line`` 邮票卡样式与扇形叠放。
  3. `.folder-inside` 由「用药说明书列表」改为「邮票收藏栈」的打开态容器；保留开合过渡动画，封面 `transform-origin: left` + `rotateY` 开门，内页与邮票淡入。
  4. HTML：把 `.folder-inside` 里的 manual-item 换成邮票卡结构；`toggleFolder()` 交互不变（点封面开/合，点关闭按钮合上）。
